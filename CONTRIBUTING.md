# Contributing

Amend Core is in feasibility development. Discuss substantial interface changes in an issue before implementing them. Small fixes and documented reproductions are welcome.

Contributions are under Apache-2.0; contributors retain their copyright. Submit only work you have the right to license. There is no copyright assignment or separate contributor license agreement. Do not import code with incompatible terms or assume community contributions can later be relicensed unilaterally.

Use small synthetic fixtures with documented provenance. Never include personal media, credentials or private app files. Include relevant verification and known limitations with a change. Run the ImageIO probe described in the README when changing it. There is no package build or full test suite yet.
