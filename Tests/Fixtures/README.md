# Synthetic fixtures

`direct-fetch.wav` is generated test audio: 100 ms of a 500 Hz square wave,
16,000 samples/second, mono, signed 16-bit PCM. It contains no recorded person,
third-party media or identifying metadata. It is distributed under the repository
license. A pinned raw GitHub URL permits an end-to-end HTTPS fetch check without
using someone else's media or disabling certificate validation.
